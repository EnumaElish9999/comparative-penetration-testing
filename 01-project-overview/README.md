# 01 — Project Overview

## Project

**Comparative Review of Penetration Testing Tools**

The project evaluates four penetration-testing tools:

- Nmap
- Burp Suite
- SQLmap
- Metasploit

Testing was conducted against **Metasploitable 2**, an intentionally vulnerable virtual machine.

## Aim

The project aimed to identify evaluation criteria for penetration-testing tools, implement the selected tools in a controlled environment, assess their capabilities and performance, and compare the results.

## Objectives

1. Evaluate the selected penetration-testing tools.
2. Implement the tools in a controlled virtual environment.
3. Conduct penetration-testing activities against Metasploitable 2.
4. Compare the tools using usability, reporting/analysis and performance.
5. Identify the strengths and limitations of each tool.

## Scope

The project focuses on the comparative analysis of Nmap, Burp Suite, SQLmap and Metasploit within penetration testing.

## Stakeholders

The report identifies cybersecurity professionals and organisations as the key stakeholders.

## Ethical Considerations

The virtual machines used for testing were intentionally vulnerable and contained fake data. Testing was carried out in a controlled environment for security assessment purposes.
