# 08 — Project Management

## Management Tool

**Monday.com** was used as the primary project management platform.

The project was divided into five phases with sub-items. Tasks were tracked using status, priority, due dates, baseline and dependency information.

## Tracking

A Gantt chart was used to visualise the project schedule and monitor progress.

## Alternatives Considered

The report considered:

- Asana
- Jira
- Microsoft Project

Monday.com was selected as the primary project management tool for the project.

## Critical Review

### Outcome

The project met most of its objectives by evaluating usability, reporting capabilities and performance across the four tools.

### Time Management

The project was completed within the planned timeframe. The report notes that it could potentially have been completed approximately one week earlier.

### What Worked

The comparison produced useful information about which tool is better suited to different requirements.

### What Could Be Improved

A more focused project could have concentrated on a specific penetration-testing area, such as vulnerability testing tools or web application analysis.

### Future Development

Potential future work includes investigating how different tool parameters affect results and efficiency, and comparing automated and manual penetration testing.
